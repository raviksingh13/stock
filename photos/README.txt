One folder per item. The folder name is the item id from stock.csv.
Inside it, name the photos 1, 2, 3 ... up to 8.
Example: photos/latitude-7320/1.jpg, photos/latitude-7320/2.jpg
Number them in order with no gaps (the page stops at the first missing number).
Accepted: .jpg .jpeg .png .webp (iPhone HEIC photos will not show).
